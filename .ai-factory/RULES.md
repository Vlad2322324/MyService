# RULES for AI Factory

1. Не вносить изменения вручную в `internal/api/generated` — генерируйте через `oapi-codegen`.
2. Все изменения схемы БД — через SQL миграции в `migrations/`.
3. Логи не должны содержать секреты (пароли, ключи).
4. CI должен запускать codegen и тесты; если сгенерированные файлы не в репозитории — CI должен генерировать их и проверять соответствие.
5. Коммиты должны соответствовать Conventional Commits (feat/fix/docs/chore).
